# External Verification

Molt 不能只在记忆内部循环。任何会随时间变化的判断，都需要外部事实校准。

## 高衰减，优先核验

- 模型新版本、上下文、工具能力、价格。
- 产品发布状态：preview、beta、GA、下线。
- 监管、诉讼、收购、融资。
- benchmark、市场份额、ARR、估值。

## 中衰减

- 生态合作、战略联盟。
- 框架、协议、SDK 的重大变更。
- 平台政策和分发渠道规则。

## 低衰减

- 公司长期战略。
- 技术范式。
- 用户长期偏好。

## 搜索纪律

- query 带当前年份，必要时带月份。
- 至少两个角度验证同一判断。
- 优先官方文档、财报、监管文件、可信媒体、当事人公开声明。
- 主动搜索反驳信号。
- 证据冲突时标“信息不足”，不要硬下结论。

## 记录格式

```markdown
| 判断 | 查询 | 新证据 | 处理 |
|---|---|---|---|
| ... | ... | 仍成立 / 精确化 / 不真 / 信息不足 | 改写 / 标 verified / 标 unverified |
```

处理方式：

- 仍成立：标 `(verified YYYY-MM-DD)`。
- 需精确化：重写判断。
- 已不真：删除或反转，并在 molt 文档记录旧判断。
- 信息不足：标 `unverified, last attempt YYYY-MM-DD`。
