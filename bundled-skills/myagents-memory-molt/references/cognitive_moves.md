# Molt Cognitive Moves

每次 molt 都必须完成五个动作。缺一个，就会退化成普通整理。

## 1. 模式挖掘

跨时间寻找重复出现的结构，而不是总结流水账。

阅读顺序：

1. `04-MEMORY.md` / `MEMORY.md`：已经成型的方法论和世界观。
2. 近期 30 天日志：看现在实际在做什么。
3. 关键 topic：最活跃的、最久没动的、与 flags 相关的。
4. 上次 molt：检查承诺是否兑现。

寻找的形状：

- 同一教训出现 3 次以上。
- 同一用户纠正反复出现。
- 写进 MEMORY 后仍然重复违反。
- 长期稳定的信念。
- 长期没有影响的项目、方向或习惯。
- 旧规则和现在行为不一致。

完成判定：至少找到 3 个跨时间的结构性形状。

## 2. 信念审计

对 MEMORY 里的世界观、长期判断、协作原则逐条施压：

1. 这条什么时候建立，当时有什么证据？
2. 今天证据还在吗？
3. 能不能用今天的证据论证反面？
4. 什么会让我改变判断？
5. 这是用户透传，还是我独立验证后接受？

完成判定：

- 至少一条判断被改写、降级、删除或标 `unverified`。
- 透传判断不要伪装成独立结论。

## 3. 外部事实核验

对会衰减的事实判断做外部搜索：

- 模型版本、能力、价格。
- 产品发布状态。
- 法规、生态、市场格局。
- 任何带具体数字或“最新”的判断。

完成判定：至少 3 项高衰减判断被验证、精确化或标为信息不足。

## 4. 身份一致性

对 SOUL 每条原则做行为对照：

- 最近一次遵守它的例子是什么？
- 最近一次违反它的例子是什么？
- 违反是偶发，还是说明 SOUL 不再真实？
- 要修 SOUL，还是修行为机制？

完成判定：SOUL 每条都有“不动 / 改写 / defer”的明确结论。

## 5. 综合落地

必须形成五件具体产出：

1. 一个新接受的信念。
2. 一个新拒绝的旧信念。
3. 一个升级到 SOUL / USER / MEMORY 的模式。
4. 一个该停止、降级或休眠的方向。
5. 一个能力缺口，以及后续机制。

每件都问：

- 这是我相信的，还是我希望被认为相信的？
- 下次 molt 能不能复测？
- 是否已经落地到元层文件，而不只写在 molt 文档里？
