## 落地纪律

- 不要写“等用户决定”。在权限允许范围内自审后落地。
- 不要只写 molt 文档，必须同步修改元层文件。
- 不要大规模重写 topic；topic 重构留给 gardener 或专项任务。
- progress 文件必须无未标记 checkbox。
- 如果有 git 仓库，只 commit，不 push。
