## 1. 信息架构

MyAgents 使用双层注意力导航：

- 全局侧栏回答“产品能力和资源在哪里”；
- 顶部 Tab 回答“哪些工作正在占用注意力”；
- 当前 Tab 内容只表达该资源内部状态，不建立第三套全局导航。

侧栏属于 App Shell，不属于 Launcher。所有主页面、Chat、Task Center、Skills & Tools、Settings 和 Record Detail 都由顶部 Tab 拥有；同类单实例页面重复打开时聚焦已有 Tab。

## 2. 布局与响应式

- 全局侧栏从窗口顶部延伸到底部；右侧才是 Tab chrome 和当前内容。
- 展开侧栏、rail、Header 和工作区面板尺寸统一消费 `src/renderer/index.css` 的结构 Token，不在组件复制像素。
- 手动收展时一次提交最终布局宽度，视觉层使用 clip/opacity/translate 完成 200ms 过渡；主导航功能图标保持屏幕坐标稳定，品牌行搜索在标题右侧与 rail 图标槽之间平滑移动，Logo 交叉淡入淡出。
- 窄窗自动进入 rail；无法兑现的展开控制不显示。右侧工作区在空间不足时成为 Overlay，不挤压对话主栏。
- 展开侧栏默认 256px，可在右缘外侧约 6px 热区拖到 224–480px；热区避开侧栏内部滚动条，hover/focus 提示调整，拖动实时跟随，松手保存到既有本地侧栏偏好。双击或聚焦后 Enter 恢复默认；左右键每次调整 8px，Home/End 到上下限。rail 和资源 flyout 尺寸不参与调宽。
- 侧栏所在的 Shell 绘制层高于页面内部工作区的覆盖层与点击关闭层，使外缘热区始终可拖；App 级模态框仍覆盖整个 Shell。不能只提高热区子元素的层级。
- 宽度跨 Tab、收展和重启保留；缺失/非法宽度回默认，有限越界值钳制。自动 rail 不覆盖用户模式或展开宽度。取消、失焦、指针中断、卸载或进入 rail 撤销尚未提交的拖动并释放捕获；保存失败保留当前宽度并明确提示未能记住。
- 用户拖动时按帧更新几何，不播放收展缓动、不逐帧持久化；侧栏与同级 Tab/主内容的动画共享动态宽度。拖动遮罩沿用原生浏览器的 `data-suppress-browser` 协议，只暂停呈现，不释放浏览器实例。
- Chat 按自身容器实际可用宽度与工作区 inline 尺寸选择 inline/overlay，分屏比例只计一次；不以窗口宽度替代容器宽度。首次有效测量决定初始工作区显隐，后续尺寸变化不改用户开关意图；隐藏 Tab 的零尺寸不作为有效几何。尺寸改变时由既有 disclosure owner 结束过期收展动画，避免跨布局重播；尺寸观察只发布布局决策变化，不逐像素重渲染整个 Chat。
- `prefers-reduced-motion` 下取消收展动画并立即切换最终状态。
- macOS 红绿灯和 Windows 窗口按钮使用原生控件与各自安全区，resize/fullscreen 期间不发生位置跳变。

## 3. 顶部 Tab

- Tab 保留 active、关闭、拖拽、溢出、生成中和未读语义；侧栏不复制 Tab 的“已打开”状态。
- active/hover 使用 `hover-bg`，active 增加 2px Accent 底线，不使用常驻阴影。
- 顶部“+”始终强制新建 Launcher；侧栏“新对话”优先聚焦最左侧已有 Launcher，不存在时再新建。
- Tab 标题和内容加载互相独立：点击资源后立即创建并激活目标 Tab，启动过程在目标内容内部反馈。失败撤销临时 Tab 并回到仍存在的前一 Tab；迟到结果不能抢回用户已经切走的 Tab。

## 4. 全局侧栏

展开态从上到下为：

1. 原生窗口 chrome 与固定收展控制；
2. App Icon 与 MyAgents 产品身份，右侧为搜索图标，与底部通知图标水平对齐；
3. 新对话、自动化任务、技能与工具、AgentNet 局域网络，以及“更多”菜单（按顺序包含条件可用的 Space 协作空间、聊天机器人 Bot，以及实验室开启后的 Team AI）；
4. Agent 工作区与 Session 树；
5. 小助理、设置，以及最底部的账号/通知合并行。

主导航与底部入口使用连续行，不用横线或逐组卡片切割。层级依靠组间留白、标题、缩进、文字权重和单一选中面表达。

侧栏 14px 行标签统一做 1px 向上的文字光学校正：导航、工作区与归档、Session 标题、账号及空状态创建按钮共用 `global-sidebar-label`。Flex 继续居中行盒和图标槽；校正只作用于字形呈现，并与收展的水平变换独立组合。12px 分组标题、日期和计数，以及独立图标按钮不套用这份校正。

展开态最底行左侧为可伸缩的 MyAgents 账号入口，右侧为固定 32px 的通知图标按钮，两个区域独立点击。未登录或认证失效显示“登录 MyAgents”，点击打开/聚焦已有 Space Tab，沿用其登录流程；已登录显示头像与名称，点击打开账号菜单而不切 Tab。菜单顶部账号信息整行打开原资料编辑弹窗，保留账号套餐与退出登录，不再提供“设置”菜单项。资料编辑归 Shell 呈现，不依赖 Space Tab。Space 页面内部不再重复提供账号入口。

侧栏右侧操作统一使用 32px 热区与 16px 右边距：品牌行搜索、工作区标题的 +、底部通知，以及工作区 hover/focus/menu 中最右侧的新对话和 Session 更多按钮保持同一视觉轴；相邻的更多按钮统一间距 4px。常驻与按需显示只决定可见时机，不改变位置。资源行的滚动容器内边距计入这份右边距，保留原生 overlay scrollbar 安全留白。

rail 最底部仅保留通知图标，不显示账号头像或隐藏账号焦点；小助理与设置保留原图标入口。账号名称过长时截断，不压缩通知区域。

通知按钮与顶部搜索共用 200ms transform 收展过渡与 easing，两者始终保留同一个按钮节点，快速反向操作可连续插值；纵坐标固定。通知的静态承载行在 rail 中不留下透明命中区域，账号保持展开态独立可点击。Reduced Motion 下两者立即切到最终位置。

侧栏导航与资源行使用不超过 8px 的局部圆角；不改变全局 Theme 圆角。资源选中使用稳定的 `paper-inset` 底色与短 Accent 指示线，hover/focus/menu 使用较轻的 `hover-bg`；选中优先于悬停。分组标题和会话日期使用完整的 `ink-muted`，不叠透明度；“Agent 工作区”标题保持既有 12px 左边距。

rail 中：

- 搜索替代顶部 App Icon，与功能图标保持同一视觉轴；
- 工作区入口打开可交互 flyout，其他入口显示即时 `Tip`；
- flyout 覆盖主内容而不推动布局，资源树在稳定高度内独立滚动；
- hover/focus 离开真实交互区域后才关闭，展开树枝造成的边界变化不能误关；
- Escape 关闭并回到入口，菜单打开时不重复显示 Tooltip。

展开态品牌标识是官网链接，只使用 pointer 和键盘 Focus，不铺导航选中底色；右侧搜索是独立按钮。rail 中隐藏官网链接并移出焦点序列。浏览器开发模式沿用搜索不可用的边界，此时 rail 保留 Logo 官网入口。

## 5. 工作区与 Session 树

- 工作区按置顶、最近打开、名称稳定排序；归档项进入默认收起分组。
- 默认工作区只在首次有效解析时种子展开一次；之后尊重用户跨重启保存的展开选择。
- 展开工作区首批显示 5 个 Session，“展开更多”每次增加 5 个；当前进程内折叠不重置数量。
- 工作区整行只切换树；新对话和更多菜单是独立动作。Session 整行打开或聚焦 Chat。
- 展开/收起使用 200ms 高度与透明度过渡，不逐条 stagger；Reduced Motion 下立即完成。
- 加载和失败按工作区隔离，使用同高静默占位或原位重试，不遮蔽其他树枝。
- 工作区和 Session 行不允许文本选中；右键只进入该资源的上下文菜单。
- 行内更多菜单绝对覆盖日期槽，不静态占用标题宽度。长标题只在真实截断并持续 hover 后显示完整 Tip。
- “Agent 工作区”标题的 +、空状态按钮与 Launcher 工作区选择器的“添加文件夹”都打开同一个“新建 Agent”面板（`NewAgentPanel`，挂在 GlobalSidebar，打开状态由 App 持有）。面板是同一弹窗内的“列表 → 详情”导航：列表上方是不带标题的官方类型（本地项目、内置模板），下方是“我的模板”与“添加模板”；本地项目先调起系统选择器再进详情；详情页确认名称、图标（与 Agent 设置共用 `WorkspaceIconGrid`）和路径。已登记或已归档的文件夹直接 toast 报错并作废本次选择；创建只走 `addProject` 的 create-only 策略。创建成功后不切 Tab，只把新工作区滚入可见并闪一次。
- 资源树始终只有一个持久选中面：Launcher 选择工作区时选中工作区；Chat 已进入 Session 时只选中 Session。工作区名称固定使用 medium 字重、会话使用 regular，不随 hover/focus 或菜单开关改变文字宽度。

Session 注意力信号：

- 运行中：success 脉冲点；
- 未读：Accent 静态点；
- 运行中优先于未读；
- 当前选中、后台已打开和普通历史不新增额外点状状态。

工作区名称右侧复用同一注意力点，汇总该工作区的 Chat Tab 状态：任一会话运行中显示 success 脉冲点；没有运行会话但存在任一未读时显示 Accent 静态点；其余不显示。汇总不受树枝收展、历史加载、分页、收藏或自动化来源筛选影响，尚未进入历史列表的新会话也参与。状态槽宽度固定，状态变化不挤动标题；hover/focus 时沿用既有动作覆盖层。此处不改变 Session 注意力来源，也不将独立的通知计数混入运行/未读语义。

## 6. 行内动作和菜单

- 资源行的动作层只在 hover、focus-within 或菜单打开时显现，并用短渐变遮住实际重叠内容；隐藏时不截获鼠标。
- 工作区动作遮罩复用该行最终底色，叠在宿主表面上（展开侧栏为 Shell，rail flyout 为 elevated）；保持右侧圆角连续，不猜测 Accent 混色比例。
- 工作区右侧低频“更多”在左，高频“新对话”在最右，收展和菜单状态不交换位置。
- 工作区菜单顺序为 Agent 设置、打开所在文件夹、置顶/取消置顶、归档、移除；危险动作收尾。
- Chat 的 Session 菜单顶部以只读单行展示该 Session 的 Runtime 图标与名称；下方是可复制的 `SessionID: <id>`，再往下是会话操作。Runtime 名称来自 Session 的执行身份，加载期间不使用工作区当前默认值代替。搜索结果复用同一菜单。
- 任务导航行的快捷“+”只在展开态 hover/focus 出现，并阻止触发父级导航。

## 7. 通知、小助理与 Shell 弹层

- 通知 Bell 是常驻底部入口；未读只显示 6px Accent 圆点，不显示数字。
- 消息中心、rail 工作区 flyout 和小助理使用统一 elevated surface、圆角、阴影与 close-layer，但保留各自尺寸和内容结构。
- 消息中心为 fixed 非模态面板：Header 只保留“消息中心”和“全部已读”，正文独立滚动，加载/空态/局部失败不改变外壳尺寸。
- 通知项不显示来源图标或独立未读点；14px 标题、12px 摘要/时间，通过文字深浅表达已读。正文最多三行。
- 点击通知是唯一 read trigger，并继续执行目标导航。目标接纳后关闭；外链失败保留面板和复制 URL 的恢复入口。
- 外部点击、Escape、Cmd+W 关闭当前 Shell 弹层并恢复入口焦点；同层弹层互斥。

## 8. 搜索与右侧工作区

- 历史搜索点击后立即出现同尺寸面板壳；冷模块只替换内部内容，不重建 Backdrop 或重播入场动画。
- 品牌行搜索入口在展开与 rail 中始终是同一个 16px 图标、32px 高度的按钮，hover/focus 可预取并显示即时 Tip。空 query 是浏览全部历史并使用虚拟列表；非空 query 使用后端有界结果。
- 浏览态只保留“全部/收藏”和工作区筛选，来源用行内 Tag 表达。
- Chat 右侧工作区 Header 只展示身份、分支和路径，不显示易过期的文件聚合计数。
- 展开态最右侧依次为 Agent 设置和收起；隐藏后展开按钮占据同一最右槽位。面板与 Chat 之间使用局部短分隔，不使用通顶边框。
- 右侧工作区顶部操作统一为 32px 热区；文件树行高为 28px，普通行、重命名行、吸顶祖先和滚动定位统一消费同一个 `rowHeight`。
- 文件预览工具条使用同一 32px 操作尺度，文字按钮为 14px；先为动作区保留宽度，再截断长文件名；预览面不足 480px 时模式切换单独占一行，文档阅读宽度维持原样。
- Agent 能力初始收起，用户展开后才分配列表高度和渲染内容。

## 9. 全局产品 Tab

### 技能与工具

“技能与工具”是单实例 Tab，顶部使用“技能 / 插件 / 工具”三个下划线子 Tab，不使用胶囊分段器。页面标题使用 20px，描述使用 14px，内容最大宽度遵循现有 `max-w-4xl`。

标题右侧显示随客户端打包的 MyAgents 工具市集横幅，中英文素材随语言切换；三个子 Tab 共用该入口。横幅宽 360px、比例 3:1，窄窗口可换行并限制在容器宽度内。它是有可访问名称与键盘焦点的按钮，点击聚焦协作空间中的官方空间工具列表；构建不可用、配置尚未加载或开发者关闭协作空间时隐藏。

页面只有一个外层主滚动；子 Tab 行到达顶部后才 sticky。技能、插件和工具列表不得各自建立与页面并列的主滚动区。旧 Settings deep link 统一重定向并聚焦该 Tab。

### Team AI

Team AI 是带 @ 图标的单实例管理 Tab。入口位于侧栏“更多”末项，由“设置 → 关于 → 实验室 → Team AI 面板”控制，默认关闭。开关只控制入口显示；关闭时保留已打开的 Tab、工作区用途、渠道连接和任务运行。

页面按群聊、私聊管理共享 Agent 的配置与会话，不展示对话正文；查看 Session 时打开或聚焦对应 Chat Tab。Project 的 `purpose=team-ai` 表示工作区用途，工作区仍在普通资源树中展示。

- **页头**左侧为 Agent 切换器，菜单包含 Team AI 列表、创建和加入已有工作区；右侧为“Agent 设置”和更多菜单（在文件管理器中定位工作区、连接聊天机器人、移出 Team AI）。创建复用 `NewAgentPanel` 与 mino 模板；加入复用 `AgentWorkspacePickerDialog`。加入或移出只更改用途，不移动或删除工作区。
- **左侧**分为已连接 Bot 和会话列表，不提供搜索。Bot 列表有独立滚动区域，不挤占全部列表空间；每行显示平台、名称与连接异常等必要状态。点击 Bot 或“+”直接打开共用的 `ChannelOverlay`；它与 Agent 设置面板互斥，关闭后不露出另一层设置。
- **会话列表**跨 Bot 平铺，按最近活动排序。每行显示名称及“群聊/私聊 · Bot 名”，头像附平台标识；名称缺失时使用渠道配置中的名称，再回退到短 ID。执行中、异常状态单独标注，其余显示相对时间。时间与右侧统计一致，来自当前 Session；无当前 Session 时使用最近历史 Session。
- **右侧**依次为聊天名称与来源、离线提示、统计、配置、会话。停用的渠道可直接启用；其他渠道设置从左侧 Bot 进入。统计只展示 Session 元数据提供的近 7 天会话数、累计对话轮次和最近活跃时间。
- **配置**默认收起，显示“跟随 Agent 默认”或“专属设置”及配置摘要。展开后可调整 Runtime、模型、推理强度和工具，不包含权限。修改后保存为此聊天的专属配置，兼容的改动同时应用到当前 Session。Runtime 或不兼容模型只能在新会话中生效：先保存，再询问是否立即新建；取消不撤销已保存配置，当前 Session 已使用该配置时不弹窗。“恢复跟随 Agent 默认”只影响以后创建的 Session。
- **会话**合并当前与历史 Session，复用侧栏行样式、运行指示和菜单：当前会话有“当前”标签，日期在悬停时由更多按钮替换。点击打开 Chat Tab；菜单提供打开、设为当前会话、复制 ID。只能把本聊天下的历史 Session 设为当前，不要求用户另选绑定目标。新建入口位于本段标题右侧；停止执行在 Chat Tab 中操作。
- 离线时可浏览历史；本页的新建、换绑和配置修改要求渠道在线。配置保存、应用到当前 Session、绑定持久化和平台通知的结果分别反馈。换绑不停止旧任务，回复仍遵循既有投递规则，见 [IM 技术文档](../tech_docs/im_integration_architecture.md#team-ai-管理投影)。
- 宽度不足 720px 时，列表与详情二选一；详情顶部提供“全部会话”返回入口。

### Settings

Settings 是单实例 Tab，内部导航顺序为：模型供应商、通用设置、聊天机器人 Bot、桌面宠物、使用统计、网络代理、外部调用、快捷键、关于。连续点击「关于」中的 MyAgents 标识解锁后，左侧在「关于」下方显示独立的「开发者」页；「默认 Integrated Runtime」放在该页，不在「实验室」展示。技能、插件和工具不在 Settings 重复出现。

- 网络代理是独立子页；供应商验证失败的“配置代理”直接进入该页。
- “更多”中的聊天机器人 Bot 打开或聚焦同一个 Settings Tab 并定位 Bot；点击后关闭菜单，侧栏主导航高亮“设置”。底部设置入口定位模型供应商。
- About 在联系方式后展示软件授权：AGPL-3.0-only 社区许可、闭源商业授权、许可证、源码、第三方声明和商业授权邮件均可达。
- “获取源代码”固定打开 GitHub 仓库默认页，不跟随当前版本、tag 或开发分支。
- Settings 与 Skills & Tools 分别保留自己的导航、草稿和弹层状态；app-global 配置 effect 由配置层持有，不随页面 mount。
- 两者的初始默认页只用于首次挂载；一次性导航消费后保留当前子页，重复的显式导航仍生效。Settings 无目标打开请求定位模型供应商，Skills & Tools 无目标打开仅聚焦已有 Tab。

## 10. 不变量

- App Shell 异步失败不能拖垮当前可用 Tab、导航或其他工作区。
- hover 动作、未读状态和菜单不能改变资源行的静态宽度。
- 同一导航动作只存在一套语义图标和一个 route owner。
- Shell 只投影 Session/Task/Notification authority，不从 DOM 或颜色反推业务状态。
